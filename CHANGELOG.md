# Changelog

All notable changes to NowPlaying are documented here.

## [0.2.0] - 2026-10-07

### Added

- Added a polished control page for configuring the OBS overlay.
- Added Default and Ambient overlay skins.
- Added live skin previews.
- Added dynamic recommended OBS Browser Source dimensions.
- Added overlay URL reveal and clipboard copy.
- Added Spotify connection and playback status.
- Added system tray support.
- Added Windows application icon.
- Added empty, loading, and error states.

### Improved

- Improved overlay animations and track transitions.
- Improved playback position and progress tracking.
- Improved artwork handling and browser memory cleanup.
- Improved control page layout and responsive behavior.
- Improved OBS setup experience.
- Refined typography, spacing, buttons, and controls.
- Reduced unnecessary debug output.

### Fixed

- Fixed stale overlay URL copy messages.
- Fixed skin preview synchronization when changing skins.
- Fixed artwork object URLs accumulating in the browser.
- Fixed various playback and overlay state synchronization issues.

### Notes

- Currently supports Spotify through Windows Media Session / SMTC.
- No Spotify account connection or API credentials are required.
